# 学习与开发路线

下列按每周 20 小时安排，是初步节奏；以实际验收调整，不是交付期限。

| 阶段 | 内容 | 验收成果 | 当前状态 |
| --- | --- | --- | --- |
| 第 1 周 | JavaScript、开发工具、Git | 原生内存待办练习 | 待开始 |
| 第 2 周 | Vue 3、响应式、组件与表单 | Vue 待办页面 | 待开始 |
| 第 3 周 | HTTP、Maven、Spring Boot 与 MVC | 内存待办接口 | 待开始 |
| 第 4 周 | MyBatis、MySQL、联调 | 页面→API→数据库完整保存读取 | 待开始 |
| 后续 | 登录、归属权限、随手记 | 真实个人记录闭环 | 待细化 |
| 后续 | 联系人、信箱、授权与定时发送 | 人际关心闭环 | 待细化 |
| 最后 | 测试、运行文档、部署学习与项目复盘 | 可复现运行与可解释的求职材料 | 待细化 |

## 本周 JavaScript 要点

变量与作用域、对象引用、函数与回调、数组方法、解构、模块、DOM 事件、Promise、async/await、fetch、JSON。理解 TypeScript 类型不会自动校验运行时数据。

## 当前练习：原生待办

源文件由用户亲自填写，暂不引入 Vue 或后端。

页面包含标题输入框、添加按钮、列表、完成按钮、删除按钮，以及总数/未完成/已完成统计。

验收：
- 空白标题不能添加。
- 同名任务可以独立存在和操作。
- 每个任务使用稳定 ID，操作不依赖数组下标。
- 完成、重新打开、删除后统计正确。
- 数据存于内存，刷新清空。
- 用户能够解释事件触发、数据改变与页面更新的关系。

先完成静态 HTML/CSS，再实现交互。每周建议学习 5 小时、实现 10 小时、调试 3 小时、记录和 Git 复盘 2 小时。
